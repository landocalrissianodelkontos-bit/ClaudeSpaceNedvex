| Путь | Что лежит |
|---|---|
| `Реестр_договоров_РСО_Волна_Резорт.xlsx` | реестр: лист «Договоры РСО», лист «Доп. соглашения», лист «Справка» (источники и итог поиска) |

`Водоканал_123-В_01.02.2020.pdf`; для доп. соглашений
`<РСО>_<№ договора>_ДС<№>_<ДД.ММ.ГГГГ>.pdf`.
